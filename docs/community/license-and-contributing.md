# Licencia y contribución

## Licencia y contribución

El proyecto se distribuye bajo **GPL-2.0-only**. Las modificaciones y redistribuciones deben conservar las obligaciones de esa licencia y la atribución correspondiente.

Antes de proponer o publicar un cambio:

- mantener el alcance de CLRS como lenguaje educativo;
- respetar las fronteras entre dominio, VS Code y Webview;
- acompañar el cambio con pruebas proporcionales al riesgo;
- actualizar esta documentación técnica cuando cambien contratos, rutas, esquemas o procesos de desarrollo.
